## 📥 如何从 Firebase Console 下载配置文件

### 重要提醒：iOS 和 Android 配置文件完全不同！

同一个 Firebase 项目，iOS 和 Android 需要**分别下载各自的配置文件**：
- **iOS**: `GoogleService-Info.plist` (XML 格式)
- **Android**: `google-services.json` (JSON 格式)

---

### 1️⃣ 下载 iOS 配置文件

1. 打开 [Firebase Console](https://console.firebase.google.com/)
2. 选择对应的 Firebase 项目
3. 点击左侧菜单的 **齿轮图标** → **项目设置**
4. 滚动到 **您的应用** 部分
5. 找到 **iOS 应用**（Bundle ID: `id.app.guardian`）
6. 点击 **下载 GoogleService-Info.plist** 按钮
7. 将下载的文件放到对应位置

#### iOS Staging 配置
```bash
# Firebase 项目: guardian-indonesia-stagi-8504c
# 下载后替换:
ios/Firebase/Staging/GoogleService-Info.plist
```

#### iOS Production 配置
```bash
# Firebase 项目: guardian-indonesia
# 下载后替换:
ios/Firebase/Production/GoogleService-Info.plist
```

#### iOS Development 配置
```bash
# 选项 A: 复用 Staging 配置
cp ios/Firebase/Staging/GoogleService-Info.plist \
   ios/Firebase/Development/GoogleService-Info.plist

# 选项 B: 使用独立配置（如有独立的 Development Firebase 项目）
# 从 Firebase Console 下载并替换:
ios/Firebase/Development/GoogleService-Info.plist
```

---

### 2️⃣ 下载 Android 配置文件

1. 打开 [Firebase Console](https://console.firebase.google.com/)
2. 选择对应的 Firebase 项目
3. 点击左侧菜单的 **齿轮图标** → **项目设置**
4. 滚动到 **您的应用** 部分
5. 找到 **Android 应用**（包名: `id.app.guardian`）
6. 点击 **下载 google-services.json** 按钮
7. 将下载的文件放到对应位置

#### Android Staging 配置
```bash
# Firebase 项目: guardian-indonesia-stagi-8504c
# 下载后替换:
android/app/src/staging/google-services.json
```

#### Android Production 配置
```bash
# Firebase 项目: guardian-indonesia
# 下载后替换:
android/app/src/production/google-services.json
```

#### Android Development 配置
```bash
# 选项 A: 复用 Staging 配置
cp android/app/src/staging/google-services.json \
   android/app/src/development/google-services.json

# 选项 B: 使用独立配置
# 从 Firebase Console 下载并替换:
android/app/src/development/google-services.json
```

## 📱 配置文件格式区别

### ✅ iOS 配置文件（GoogleService-Info.plist）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>GOOGLE_APP_ID</key>
    <string>1:xxx:ios:xxx</string>  ← 注意包含 :ios:
    <key>CLIENT_ID</key>
    <string>xxx.apps.googleusercontent.com</string>
    <key>REVERSED_CLIENT_ID</key>
    <string>com.googleusercontent.apps.xxx</string>
    <key>API_KEY</key>
    <string>AIzaXXXXXXXXXXXXXXXXXXXXXXXX</string>
    <key>BUNDLE_ID</key>
    <string>id.app.guardian</string>
    ...
</dict>
</plist>
```

**关键字段验证**：
- ✅ `GOOGLE_APP_ID` 必须包含 `:ios:`
- ✅ `BUNDLE_ID` 必须是 `id.app.guardian`
- ✅ 文件格式必须是 XML（以 `<?xml` 开头）

---

### ✅ Android 配置文件（google-services.json）

```json
{
  "project_info": {
    "project_number": "123456789",
    "project_id": "your-project-id"
  },
  "client": [
    {
      "client_info": {
        "mobilesdk_app_id": "1:xxx:android:xxx",  ← 注意包含 :android:
        "android_client_info": {
          "package_name": "id.app.guardian"
        }
      },
      "api_key": [
        {
          "current_key": "AIzaXXXXXXXXXXXXXXXXXXXXXXXX"
        }
      ]
    }
  ]
}
```

**关键字段验证**：
- ✅ `mobilesdk_app_id` 必须包含 `:android:`
- ✅ `package_name` 必须是 `id.app.guardian`
- ✅ 文件格式必须是 JSON（以 `{` 开头）

## 🚨 常见错误

### ❌ 错误 1：下载错了平台的配置文件

**症状**：
- iOS 配置文件是 JSON 格式（以 `{` 开头）
- Android 配置文件是 XML 格式（以 `<?xml` 开头）

**原因**：
- 在 Firebase Console 选错了应用类型

**解决**：
- iOS 要选择 **iOS 应用**，下载 `.plist` 文件
- Android 要选择 **Android 应用**，下载 `.json` 文件

---

### ❌ 错误 2：Bundle ID / Package Name 不匹配

**症状**：
- 应用启动时 Firebase 报错：`FirebaseApp initialization failed`

**原因**：
- 配置文件中的标识符与应用不匹配

**解决**：
- iOS: 检查 plist 中的 `BUNDLE_ID` 是否为 `id.app.guardian`
- Android: 检查 json 中的 `package_name` 是否为 `id.app.guardian`

---

### ❌ 错误 3：放错了目录

**症状**：
- 构建成功但 Firebase 不工作

**原因**：
- 配置文件没有放到正确的目录

**解决**：
- iOS 必须放在 `ios/Firebase/{环境}/`
- Android 必须放在 `android/app/src/{环境}/`

## 🔒 安全建议

1. **不要提交真实配置到公开仓库**
   - 如果项目是私有的，可以提交配置文件
   - 如果项目是公开的，建议添加到 `.gitignore`

2. **配置文件备份**
   - 将真实配置文件保存在安全的地方
   - 使用密码管理器或团队加密存储

3. **环境隔离**
   - Development/Staging 使用测试数据
   - Production 使用真实数据
   - 确保各环境 Firebase 项目隔离

## 🛠️ 故障排查

### iOS 构建失败

**问题**: 找不到 `GoogleService-Info.plist`

**解决**：
```bash
# 1. 检查文件是否存在
ls -la ios/Firebase/Staging/GoogleService-Info.plist

# 2. 清理构建缓存
cd ios
rm -rf DerivedData
xcodebuild clean

# 3. 重新构建
cd ..
yarn ios:stg
```

### Android 构建失败

**问题**: `File google-services.json is missing`

**解决**：
```bash
# 1. 检查文件是否存在
ls -la android/app/src/staging/google-services.json

# 2. 清理 Gradle 缓存
cd android
./gradlew clean

# 3. 重新构建
cd ..
yarn android:stg
```
